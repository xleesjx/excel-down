# 통합예약 엑셀 일괄 받기

울산광역시교육청 통합예약 관리자 › 통합예약 목록에서 **이번 수업일** 수업(접수중·접수마감)의 신청자 엑셀을
크롬 즐겨찾기 버튼 한 번으로 모두 받습니다.

- **점검 웹앱으로 보내기**(1.3.0~): 파일로 저장하지 않고 창의센터 신청자 점검 웹앱 창으로 바로 넘깁니다 (`postMessage`, 웹앱 주소에만 보냄).
- **폴더에 저장**: 고른 폴더에 서버가 주는 파일 이름 그대로 저장합니다.

- 설치·사용 안내: https://xleesjx.github.io/excel-down/
- `downloader.js` — 즐겨찾기 버튼이 불러오는 실제 프로그램 (여기만 고치면 모두에게 적용)
- `index.html` — 설치 안내 페이지 (버튼 끌어다 놓기)

로그인은 각자 직접 합니다. 이 프로그램은 로그인 정보를 다루지 않으며, 신청자 엑셀은 내 PC 폴더나 같은 PC에 열린 점검 웹앱 창에만 넘깁니다.
