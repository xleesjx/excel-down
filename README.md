# 통합예약 엑셀 일괄 받기

울산광역시교육청 통합예약 관리자 › 통합예약 목록에서 **접수중**인 수업의 신청자 엑셀을
크롬 즐겨찾기 버튼 한 번으로 모두 내려받습니다. 파일 이름은 서버가 주는 이름 그대로 저장됩니다.

- 설치·사용 안내: https://xleesjx.github.io/excel-down/
- `downloader.js` — 즐겨찾기 버튼이 불러오는 실제 프로그램 (여기만 고치면 모두에게 적용)
- `index.html` — 설치 안내 페이지 (버튼 끌어다 놓기)

로그인은 각자 직접 합니다. 이 프로그램은 로그인 정보나 신청자 정보를 어디에도 보내지 않습니다.
