통합예약 엑셀 일괄 받기

통합예약 목록에서 접수중인 수업의 신청자 엑셀을 버튼 한 번으로 모두 내려받습니다.

1. 버튼 설치 (처음 한 번)

  1. 크롬 즐겨찾기바가 안 보이면 Ctrl + Shift + B를 누릅니다.
  2. 아래 파란 버튼을 마우스로 끌어서 즐겨찾기바에 놓습니다. (클릭하지 말고 끌어다 놓기)
통합예약 엑셀 일괄 받기

프로그램을 고치면 다시 설치하지 않아도 다음 클릭부터 새 버전이 적용됩니다.

2. 사용하기

  1. 통합예약 관리자 페이지에 직접 로그인합니다.
  2. 통합예약 관리 › 통합예약 목록 화면(수업 목록과 [신청 관리] 버튼이 보이는 화면)으로 갑니다.
  3. 즐겨찾기바의 [통합예약 엑셀 일괄 받기]를 누릅니다.
  4. 접수중인 수업 목록을 확인하고 [○개 받기]를 누릅니다.
  5. 파일은 C:\통합예약명단 폴더에 바로 저장됩니다. 점검 웹앱에서 평소처럼 [명단 올리기]를 누릅니다.

접수마감 수업은 대상이 아닙니다. 필요하면 직접 받아 주세요. 같은 이름의 파일이 이미 있으면 덮어쓰지 않고 이름 뒤에 (1), (2)…를 붙입니다.

3. 저장 폴더 정하기 (처음 한 번)

  1. 처음 [○개 받기]를 누르면 폴더 고르는 창이 뜹니다. C:\통합예약명단을 고르고 [폴더 선택]을 누릅니다. 폴더가 없으면 그 창에서 새 폴더로 만들면 됩니다.
  2. 크롬이 「이 사이트가 폴더의 파일을 수정하도록 허용할까요?」라고 물으면 [허용]을 누릅니다. 「방문할 때마다 허용」이 보이면 그것을 고르면 다음부터 묻지 않습니다.
  3. 버튼이 이 폴더를 기억합니다. 바꾸려면 창의 [폴더 바꾸기]를 누릅니다.
  4. 점검 웹앱의 감시 폴더도 C:\통합예약명단으로 맞춰 주세요. 크롬 기본 다운로드 폴더는 원래대로 두면 됩니다.

폴더 저장이 안 될 때는 창 아래의 「다운로드 폴더로 받기」를 누르면 예전처럼 크롬 다운로드 폴더로 받습니다. 이때 「여러 파일 다운로드」 허용 창이 뜨면 [허용]을 누릅니다.

버튼을 눌러도 아무 반응이 없을 때

관리자 사이트가 외부 프로그램 불러오기를 막는 경우입니다. 아래 비상용 버튼을 같은 방법으로 끌어다 놓고 그것을 쓰세요. 프로그램이 버튼 안에 통째로 들어 있어서, 고친 버전이 나오면 이 페이지에서 다시 끌어다 놓아야 합니다.

준비 중…

이 버튼은 선생님이 로그인한 화면에서만 동작하며, 아이디·비밀번호나 신청자 정보를 어디에도 보내거나 저장하지 않습니다. 엑셀은 관리자 사이트의 [엑셀출력]과 똑같은 요청으로 받아 선생님 PC의 폴더에만 저장합니다.
