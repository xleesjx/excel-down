통합예약 엑셀 일괄 받기

통합예약 목록에서 이번 수업일 수업(접수중·접수마감 모두)의 신청자 엑셀을 버튼 한 번으로 모두 내려받습니다.

1. 버튼 설치 (처음 한 번)

  1. 크롬 즐겨찾기바가 안 보이면 Ctrl + Shift + B를 누릅니다.
  2. 아래 파란 버튼을 마우스로 끌어서 즐겨찾기바에 놓습니다. (클릭하지 말고 끌어다 놓기)
통합예약 엑셀 일괄 받기

프로그램을 고치면 다시 설치하지 않아도 다음 클릭부터 새 버전이 적용됩니다.

2. 사용하기

  1. 통합예약 관리자 페이지에 직접 로그인합니다.
  2. 통합예약 관리 › 통합예약 목록 화면(수업 목록과 [신청 관리] 버튼이 보이는 화면)으로 갑니다.
  3. 즐겨찾기바의 [통합예약 엑셀 일괄 받기]를 누릅니다.
  4. 창에 나온 수업 목록을 확인합니다. 가장 가까운 수업일 수업이 미리 체크되어 있고, 체크를 켜고 끄면 받을 수업을 바꿀 수 있습니다.
  5. [○개 점검 웹앱으로 보내기]를 누릅니다. 점검 웹앱 창이 열리고(처음이면 웹앱에서 로그인), 명단이 파일 저장 없이 웹앱으로 바로 넘어갑니다.
  6. 점검 웹앱 창에 「명단 ○개가 왔습니다」가 뜨면 회차를 확인하고 [올리기]를 누릅니다. 결과는 이 창에도 표시됩니다.

두 창을 함께 쓰기: 어느 쪽을 먼저 열어도 됩니다. 관리자 화면에서 버튼으로 웹앱을 열었거나, 점검 웹앱 위쪽의 [통합예약 관리자 ↗]로 관리자 화면을 열었다면 두 창이 연결되어, 다음부터는 열려 있는 웹앱 창으로 바로 보냅니다(새 창·새로고침 없음). 관리자 화면을 직접 주소로 열었다면 버튼이 웹앱 창을 하나 더 엽니다.

크롬이 새 창(팝업)을 막았다고 하면, 주소창 오른쪽의 팝업 차단 표시를 눌러 「항상 허용」을 고른 뒤 다시 누릅니다. 파일로 받아 두고 싶을 때는 [○개 폴더에 저장]을 누르면 예전처럼 C:\통합예약명단 폴더에 저장되고, 점검 웹앱에서 [명단 올리기]로 올리면 됩니다.

운영이 끝나지 않은 접수중·접수마감 수업이 목록에 나옵니다. 지난 수업과 접수대기 수업은 나오지 않습니다. 다음 주 수업은 목록에 보이되 체크가 꺼져 있으니, 방학 접수처럼 함께 받아야 할 때는 체크를 켜 주세요. 같은 이름의 파일이 이미 있으면 덮어쓰지 않고 이름 뒤에 (1), (2)…를 붙입니다.

3. 폴더에 저장할 때: 저장 폴더 정하기 (처음 한 번)

  1. 처음 [○개 폴더에 저장]을 누르면 폴더 고르는 창이 뜹니다. C:\통합예약명단을 고르고 [폴더 선택]을 누릅니다. 폴더가 없으면 그 창에서 새 폴더로 만들면 됩니다.
  2. 크롬이 「이 사이트가 폴더의 파일을 수정하도록 허용할까요?」라고 물으면 [허용]을 누릅니다. 「방문할 때마다 허용」이 보이면 그것을 고르면 다음부터 묻지 않습니다.
  3. 버튼이 이 폴더를 기억합니다. 바꾸려면 창의 [폴더 바꾸기]를 누릅니다.
  4. 점검 웹앱의 감시 폴더도 C:\통합예약명단으로 맞춰 주세요. 크롬 기본 다운로드 폴더는 원래대로 두면 됩니다.

폴더 저장이 안 될 때는 창 아래의 「다운로드 폴더로 받기」를 누르면 예전처럼 크롬 다운로드 폴더로 받습니다. 이때 「여러 파일 다운로드」 허용 창이 뜨면 [허용]을 누릅니다.

버튼을 눌러도 아무 반응이 없을 때

관리자 사이트가 외부 프로그램 불러오기를 막는 경우입니다. 아래 비상용 버튼을 같은 방법으로 끌어다 놓고 그것을 쓰세요. 프로그램이 버튼 안에 통째로 들어 있어서, 고친 버전이 나오면 이 페이지에서 다시 끌어다 놓아야 합니다.
